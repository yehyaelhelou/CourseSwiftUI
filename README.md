# CourserSwiftUI

📘 SwiftUI Bootcamp – Detailed File Explanations

✅ ActionsheetBootcamp.swift
Demonstrates how to use ActionSheet to present options to the user in a sheet sliding up from the bottom. Ideal for confirmations or quick choices.

✅ AlertBootcamp.swift
Shows how to create alerts using .alert(), including customizing the message, title, and action buttons based on state changes.

✅ AnimationBootcamp.swift
Covers the basics of animating UI elements using withAnimation, explaining different animation types like easeIn, linear, etc.

✅ AnimationTimingBootcamp.swift
Details how to control animation timing, duration, delay, and easing curves to create smooth and polished effects.

✅ AnimationUpdatedBootcamp.swift
Introduces advanced animation techniques using state management to reflect more dynamic UI changes.

✅ AnyLayoutBootcamp.swift
Explores AnyLayout (iOS 16+) to dynamically switch between layouts like VStack, HStack, and ZStack at runtime.

✅ AppStorageBootcamp.swift
Explains how to use @AppStorage for storing simple persistent values (like theme settings) using UserDefaults behind the scenes.

✅ AsyncImageBootcamp.swift
Demonstrates how to load remote images using AsyncImage, with support for placeholder content during loading.

✅ BackgroundAndOverlayBootcamp.swift
Covers using .background and .overlay modifiers to layer UI elements visually in front of or behind a view.

✅ BackgroundMaterialBootcamp.swift
Introduces Apple’s Material effects (e.g., blurred glass background) used in modern UI design starting from iOS 15+.

✅ BadgesBootcamp.swift
Shows how to use .badge() to display small notification indicators (like message counts) on views like tabs or buttons.

✅ BindingBootcamp.swift
Explains the use of @Binding for two-way data flow between parent and child views.

✅ ButtonStyleBootcamp.swift
Covers how to create custom button styles by conforming to the ButtonStyle protocol.

✅ ButtonsBootcamp.swift
Basic usage of buttons in SwiftUI, with examples on handling onTapGesture and action.

✅ ColorPickerBootcamp.swift
Adds a ColorPicker that lets users select a color, and stores the selected color using @State.

✅ ColorsBootcamp.swift
Demonstrates how to use system-defined and custom colors in SwiftUI.

✅ ConditionalBootcamp.swift
Shows how to use conditionals like if, else, and ternary operators to dynamically change views.

✅ ContentUnavailableViewBootcamp.swift
Introduces ContentUnavailableView (iOS 17+) for displaying messages and illustrations when there's no available content.

✅ ContentView.swift
The entry point of the app, usually contains the main starting view of your application.

✅ ControlGroupMenuBootcamp.swift
Shows how to use ControlGroup to group controls together and Menu to present a list of options in a dropdown.

✅ DarkModeBootcamp.swift
Explains how to support Dark Mode and check the current appearance using @Environment(\.colorScheme).

✅ DatePickerBootcamp.swift
Demonstrates how to use DatePicker to select dates or times with different formatting and limits.

✅ DocumentationBootcamp.swift
Teaches how to write proper code documentation using /// to describe functions, parameters, and structures.

✅ EnvironmentObjectBootcamp.swift
Explains how to use @EnvironmentObject to share data across multiple views in the app.

✅ ExtractSubViewBootcamp.swift
How to extract parts of your view into separate reusable subviews to improve code structure.

✅ ExtractedFunctionsBootcamp.swift
Moves logic and long view definitions into external functions for better readability and maintainability.

✅ FocusStateBootcamp.swift
Teaches how to manage focus (e.g., keyboard focus on TextField) using @FocusState.

✅ ForEachBootcamp.swift
Explains how to use ForEach to dynamically generate multiple views from a collection.

✅ FrameBootcamp.swift
Details how to size and position views using the .frame() modifier and parameters like width, height, and alignment.
